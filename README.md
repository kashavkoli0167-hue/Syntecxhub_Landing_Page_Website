# Syntecxhub_Landing_Page_Website
This project is a responsive **Landing Page Website** created as **Task 2** for the Syntecxhub Frontend Development Internship.

## 🚀 Project Overview

The landing page is built using HTML and CSS to demonstrate frontend development skills such as layout design, styling, responsiveness, and UI structure.

It includes a fixed navigation bar, hero section, feature cards, and a contact section with a mail button.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox

## ✨ Features

* Responsive layout for mobile and desktop
* Fixed navigation bar with smooth scrolling
* Gradient hero section
* Styled feature cards with hover effects
* Animated buttons with transform effects
* Contact button that opens email client

## 📂 Folder Structure

```
Syntecxhub_Landing_Page_Website/
│── index.html
│── style.css
```

## 🎯 Learning Outcome

Through this project, I practiced:

* Creating a complete landing page layout
* Using Flexbox for alignment
* Applying gradients and shadows
* Using pseudo-elements (::before, ::after)
* Adding hover animations and transitions
* Making a responsive design

## 📌 How to Run

1. Download or clone this repository
2. Open `index.html` in any web browser
